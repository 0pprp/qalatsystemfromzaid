# نشر لوحة قرار ضعفاء التسديد

نفّذ السكربت على **كل قاعدة محافظة** قبل تشغيل الـ API والواجهة الجديدة.

الملف: `WeakWeekPayers_Deploy.sql`

```bat
sqlcmd -S YOUR_SQL_HOST -d DatabaseCompanyNajaf -E -I -i WeakWeekPayers_Deploy.sql
```

كرر `-d` لكل قاعدة في قائمة الفروع (GetAdmin).

بعد النجاح:

1. انشر `BE_Company` ثم `FE_Company`.
2. ادخل كمحاسب رئيسي وأنشئ مستخدم `مدير فرع` داخل تلك المحافظة فقط.
3. مدير الفرع يدخل من نفس برنامج المحاسب الرئيسي على محافظة فرعه.
4. سجّل خروجاً ثم دخولاً حتى يُحفظ `UserType` في التوكن.

لا يغيّر الدومين ولا تطبيق المندوب.
